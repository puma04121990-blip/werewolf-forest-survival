# Оборотень: Лесное Выживание

**Werewolf: Forest Survival** — 2D Top-Down Roguelite Action / Survival Arena на Phaser 3.

## Описание

Ты — оборотень, последний защитник тёмного леса. Отражай бесконечные волны охотников, вампиров и инквизиторов. Автоматическая стрельба, прокачка оружия и пассивок, боссы каждые 3 минуты.

## Как запустить

1. Клонируй репозиторий
2. Открой `index.html` в браузере (или используй любой локальный сервер)
3. Рекомендуется: `npx serve .` или Live Server

Игра полностью procedural — все спрайты генерируются кодом, внешних ассетов нет.

## Управление

- **WASD / Стрелки** — передвижение
- **Пробел** — Рывок (с неуязвимостью)
- **P** — Пауза
- На мобильных — тап для движения

## Технологии

- Phaser 3.70
- Web Audio API (процедурные звуки)
- Чистый JavaScript (ES Modules)
- Полностью procedural графика

## Структура


## Особенности

- 7 видов оружия (Кровавые когти, Волчий рык, Духи Луны, Аура Хищника, Лунный разряд, Призыв Стаи, Кровавые руны)
- 5 типов врагов + элита + босс-инквизитор с **3 фазами**
- Комбо-убийства → бонусный XP
- Криты, вампиризм, броня, реген и другие пассивки
- HUD: HP/XP, кулдаун рывка, полоска оружия, волны, тосты
- Рекорды в `localStorage`
- Процедурная готическая музыка и SFX

## Баланс

Ключевые константы — в `src/config.js` (`BALANCE`): спавн, XP-кривая, боссы, pickups.
